# 📖 Overview

Trading Journal is a desktop application built with Python to help traders review their performance, identify weaknesses, and improve through data-driven analysis.

Instead of simply displaying trading results, the application focuses on helping traders develop consistency by providing meaningful performance metrics in a clean, modern interface.

> **Analyze → Learn → Improve**

---

# ✨ Features

## 📂 Trade Import

- Import CSV trading journals
- Automatic trade loading
- Data validation

---

## 📊 Performance Analytics

- Total Trades
- Winning Trades
- Losing Trades
- Breakeven Trades
- Win Rate
- Total Profit
- Average Profit

---

## 📈 Risk Metrics

- Gross Profit
- Gross Loss
- Profit Factor
- Average Win
- Average Loss

---

## 📉 Trade Analysis

- Best Trade
- Worst Trade
- Most Traded Pair
- Pair Performance
- Current Win Streak
- Current Loss Streak
- Longest Win Streak
- Longest Loss Streak

---

## 🖥 Desktop Interface

Built using Tkinter with a custom design system.

Current Version includes:

- Import CSV

- Modern layout
- Modular architecture
